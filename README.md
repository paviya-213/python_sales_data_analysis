# python_sales_data_analysis
Python Sales Data Analysis project using Pandas , Numpy , Matplotlib and Seaborn. Includes data cleaning, sales analysis and data visualization using Google Colab.
# Project Overview
This project analyses sales data to understand revenue, product performance, monthly sales trends, and regional performance using Python.
# Objectives
Analyse total sales revenue and units sold.
Identify top-performing products.
Understand monthly sales trends.
Compare sales across categories and regions.
Clean and prepare data for analysis.
# Tools and Technologies
Python
Google Colab
Pandas
Numpy
Matplotlib
Seaborn
# Project Workflow
Created a sample sales dataset using Python.
Inspected the dataset and its data types.
Identified and handled missing values.
Removed duplicate records.
Calculated revenue using quantity and unit price.
Analysed product, monthly, category, and regional sales.
Created charts to visualise sales performance.
Generated a summary of business insights.
# Key Analysis
Total orders, units sold, and revenue.
Revenue by product.
Monthly revenue trends.
Revenue by category and region.
Top-performing product and sales month.
# Conclusion
This project demonstrates basic data cleaning, exploratory data analysis, aggregation, and data visualisation using Python. The analysis helps illustrate how sales data can support business decisions.
# Dataset
The dataset was created using Python for learning and demonstration purposes. It is sample data, not actual company sales data.
